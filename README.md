# 複雑データ分析 AI Agent デモ

このデモでは、分析コードや完成済みダッシュボードを用意しません。

複数シートを含む架空のEC事業データと、このREADMEに掲載したプロンプトだけをAI Agentへ渡し、データ理解、結合、品質検査、指標計算、原因候補の探索、可視化、経営向け提案まで実行させます。

## 使用ファイル

- `workshop_data.xlsx`：分析対象となる合成データ
- `README.md`：デモ手順とAI Agentへ渡すプロンプト

実在する顧客、企業、取引、個人情報は含まれていません。

## デモの進め方

1. AI Agentへ`workshop_data.xlsx`を添付する
2. このREADMEの「AI Agentへ渡すプロンプト」をコピーして送信する
3. Agentが自律的に分析を完了するまで待つ
4. 結果に対して「最も重要な根拠を3つ示して」「別の解釈はないか」と追加質問する

## 見どころ

- 5シートの結合と粒度の理解
- 欠損、重複、外部キー、期間の検査
- 売上、利益、返品、配送、満足度、リピートの横断分析
- 月次・地域別目標との比較
- キャンペーン効率と獲得顧客の質の分析
- 異常値や構造変化の自動発見
- 事実、仮説、提案の分離

想定時間は20～30分です。

## AI Agentへ渡すプロンプト

以下のプロンプトをそのままコピーして使用してください。

```text
あなたは、データ品質、事業分析、マーケティング分析、統計的検証を横断して実行するシニアデータアナリストです。

添付した workshop_data.xlsx だけを使い、EC事業の経営課題を特定してください。分析コードや手順は提供しません。必要な処理方法を自分で計画し、データ確認から成果物作成まで自律的に完了してください。途中で確認待ちにならず、必要な仮定は明示して分析を継続してください。

【最初に行うこと】

1. 全シートを確認し、各表の粒度、主キー、外部キー、行数、期間を整理する
2. Data Guide にある指標定義と事業ルールを読む
3. 分析計画を5～10項目で提示する
4. そのまま確認待ちせず分析を実行する

【必須のデータ品質検査】

- 主キーの重複
- 必須項目の欠損
- 外部キーの不一致
- 日付範囲外の値
- 負数または不可能な数値
- 割引率、返品フラグ、満足度の範囲
- キャンペーン期間外の紐付け
- 顧客登録日より前の注文
- 商品発売日より前の注文
- 目標テーブルの月×地域の欠落または重複

検査結果は、検査名、対象表、件数、影響、対応方針を表にしてください。異常値を勝手に削除・補完せず、原データと分析上の扱いを分けてください。

【指標定義】

Orders、Customers、Products、Campaigns、Monthly Targets を適切に結合し、次を計算してください。

- gross_sales = units × unit_price
- booked_revenue = gross_sales × (1 - discount_rate)
- net_revenue = returned=1なら0、それ以外はbooked_revenue
- gross_profit = net_revenue - units × unit_cost - returned × 800
- gross_margin = gross_profit / net_revenue
- return_rate = 返品注文数 / 注文数
- repeat_customer_rate = 2回以上購入した顧客数 / 購入顧客数
- attributed_roas = キャンペーン紐付きnet_revenue / campaign budget
- gross_profit_roas = キャンペーン紐付きgross_profit / campaign budget

ゼロ除算を避け、金額は円、率はパーセントで表示してください。

【必須分析】

1. 経営サマリー

2024年と2025年を比較し、注文数、購入顧客数、net revenue、gross profit、gross margin、return rate、平均満足度、repeat customer rateをまとめてください。前年差だけでなく、変化率、サンプル数、変化に寄与した上位要因を示してください。

2. 売上と利益の構造

地域、商品カテゴリ、商品、販売チャネル、顧客セグメント、ロイヤルティ階層別に分析し、次を特定してください。

- 売上成長に最も寄与した組み合わせ
- 売上は伸びたが利益率が悪化した組み合わせ
- 小規模でも利益率またはリピート率が高い組み合わせ
- 値引きが売上、利益率、返品率にどう関連しているか

構成比の変化と、同一セグメント内の変化を分けて説明してください。

3. 目標達成状況

月×地域単位で実績を Monthly Targets と比較し、revenue target達成率、gross margin targetとの差、return rate targetとの差、satisfaction targetとの差を算出してください。複数指標を同時に外した月×地域を優先して、重要な未達を上位10件示してください。

4. マーケティング効率

キャンペーンごとに、予算、紐付き注文数、新規顧客数、net revenue、gross profit、attributed ROAS、gross profit ROAS、返品率、90日以内の再購入率を比較してください。

短期売上への貢献、利益への貢献、獲得顧客の質、データからは因果関係を判断できない項目を区別してください。キャンペーン紐付けは観測上のアトリビューションであり、増分効果ではないことを明記してください。

5. 返品・配送・満足度

商品、サプライヤー、地域、配送日数、期間、キャンペーン別に返品率と満足度を分析し、返品が集中している条件、配送日数と返品・満足度の関係、特定期間だけ発生した異常、商品固有の問題と物流問題の切り分け候補を示してください。件数が少ないグループは断定せず、必ずサンプル数を表示してください。

6. 顧客コホート

顧客登録月をコホートとして、初回購入率、30日・90日・180日以内再購入率、累積net revenueを分析してください。獲得チャネル、顧客セグメント、ロイヤルティ階層ごとの差を示し、直近コホートは観測期間が短いことを考慮してください。

7. 異常・変化点の探索

月次推移に対して、前年比、移動平均との差、ZスコアまたはIQRなど複数の方法を使い、通常と異なる変化を探索してください。単なる季節性、母数の少なさ、構成比変化で説明できる可能性も確認してください。

【結論の作り方】

結論を次の3種類に分けてください。

1. データから直接確認できた事実
2. 事実から考えられる仮説
3. 次に検証すべき施策または追加データ

重要な主張には必ず、対象期間、比較対象、実数値、率、サンプル数を付けてください。相関を因果関係として説明しないでください。

【最終成果物】

分析結果を1つのPDFファイル「analysis_report.pdf」にまとめてください。

PDFには次の内容を含めてください。

1. 表紙
   - レポート名
   - 分析対象期間
   - 使用データ
   - 作成日

2. エグゼクティブサマリー
   - 経営課題の要約
   - 重要な発見5件
   - 推奨アクション3件
   - 主要リスクと分析上の限界

3. データ構造とデータ品質
   - 全シートの粒度、主キー、外部キー、行数、期間
   - データ品質検査結果
   - 異常値の分析上の扱い

4. KPI比較
   - 2024年と2025年の比較表
   - 実数、前年差、変化率、サンプル数
   - 変化に寄与した上位要因

5. 売上・利益構造
   - 地域、商品、チャネル、顧客属性別の比較
   - 構成比変化と同一セグメント内変化の分解
   - 値引きとの関連

6. 月次・地域別の目標達成状況
   - 月次推移グラフ
   - 目標達成ヒートマップ
   - 重要な未達上位10件

7. キャンペーン分析
   - キャンペーン別KPI比較
   - attributed ROASとgross profit ROAS
   - 新規顧客数、返品率、90日以内再購入率
   - 観測上のアトリビューションであることの注意書き

8. 返品・配送・満足度分析
   - 商品、サプライヤー、地域、配送日数、期間、キャンペーン別分析
   - 異常が集中する条件
   - 商品問題と物流問題の切り分け候補

9. 顧客コホート分析
   - 登録月別の初回購入率
   - 30日・90日・180日以内再購入率
   - 累積net revenue
   - 獲得チャネル、顧客セグメント、ロイヤルティ階層別比較

10. 異常・変化点分析
    - 前年比
    - 移動平均との差
    - ZスコアまたはIQR
    - 季節性、少数標本、構成比変化による説明可能性

11. 結論
    - データから直接確認できた事実
    - 事実から考えられる仮説
    - 次に検証すべき施策または追加データ

12. 付録
    - 指標定義
    - 結合条件
    - 計算根拠
    - サンプル数
    - 仮定
    - 分析上の除外・未評価条件

PDFは経営層が単独で読んでも判断できる構成にし、表やグラフの文字が切れないようレイアウトを確認してください。金額単位、率、対象期間、比較対象、サンプル数、凡例を明示してください。

分析完了後、最も重要な発見、作成したPDFファイル、分析上の制約を日本語で簡潔に報告してください。
```
