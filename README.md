# 複雑データ分析 AI Agent デモ

このデモでは、分析コードや完成済みダッシュボードを用意しません。

複数シートを含む架空のEC事業データと、このREADMEに掲載したプロンプトだけをAI Agentへ渡し、データ理解、結合、品質検査、指標計算、原因候補の探索、可視化、経営向け提案まで実行させます。

## 使用ファイル

- `workshop_data.xlsx`：分析対象となる合成データ
- `README.md`：デモ手順とAI Agentへ渡すプロンプト

実在する顧客、企業、取引、個人情報は含まれていません。

## デモの進め方

1. AI Agentへ`workshop_data.xlsx`を添付する
2. このREADMEの「AI Agentへ渡すプロンプト」をコピーして送信する
3. Agentが自律的に分析を完了するまで待つ
4. 結果に対して「最も重要な根拠を3つ示して」「別の解釈はないか」と追加質問する

## 見どころ

- 5シートの結合と粒度の理解
- 欠損、重複、外部キー、期間の検査
- 売上、利益、返品、配送、満足度、リピートの横断分析
- 月次・地域別目標との比較
- キャンペーン効率と獲得顧客の質の分析
- 異常値や構造変化の自動発見
- 事実、仮説、提案の分離

想定時間は約5分です。

## AI Agentへ渡すプロンプト

以下のプロンプトをそのままコピーして使用してください。

```text
あなたは、EC事業を担当するシニアデータアナリストです。

添付した workshop_data.xlsx だけを使い、EC事業の重要な経営課題を約5分で特定してください。途中で確認待ちにならず、必要な仮定を明示して、データ確認からPDF作成まで自律的に完了してください。

網羅性よりも、経営判断に直結する重要度と処理速度を優先してください。分析コードや詳細な作業手順は成果物に含めないでください。

【最初に行うこと】

1. 全シートを確認し、各表の粒度、主キー、外部キー、行数、期間を整理する
2. Data Guide にある指標定義と事業ルールを読む
3. 分析計画を5項目以内で簡潔に提示する
4. そのまま確認待ちせず分析を実行する

【データ品質検査】

- 主キーの重複
- 必須項目の欠損
- 外部キーの不一致
- 日付範囲外の値
- 負数または不可能な数値
- 割引率、返品フラグ、満足度の範囲
- キャンペーン期間外の紐付け
- 顧客登録日より前の注文
- 商品発売日より前の注文
- 目標テーブルの月×地域の欠落または重複

異常が0件の検査はまとめて記載し、異常がある検査だけ詳細を示してください。異常値を勝手に削除・補完しないでください。

【指標定義】

Orders、Customers、Products、Campaigns、Monthly Targets を適切に結合し、次を計算してください。

- gross_sales = units × unit_price
- booked_revenue = gross_sales × (1 - discount_rate)
- net_revenue = returned=1なら0、それ以外はbooked_revenue
- gross_profit = net_revenue - units × unit_cost - returned × 800
- gross_margin = gross_profit / net_revenue
- return_rate = 返品注文数 / 注文数
- repeat_customer_rate = 2回以上購入した顧客数 / 購入顧客数
- attributed_roas = キャンペーン紐付きnet_revenue / campaign budget
- gross_profit_roas = キャンペーン紐付きgross_profit / campaign budget

ゼロ除算を避け、金額は円、率はパーセントで表示してください。

【必須分析】

1. 2024年と2025年のKPI比較

注文数、購入顧客数、net revenue、gross profit、gross margin、return rate、平均満足度、repeat customer rateについて、実数、前年差、変化率、サンプル数を1表にまとめてください。

2. 重要な経営課題3件

地域、商品カテゴリ、商品、販売チャネル、顧客セグメント、ロイヤルティ階層を確認し、売上・利益の変化に最も影響した課題を3件に絞ってください。

各課題には、対象期間、比較対象、実数、率、サンプル数、寄与要因を付けてください。値引き、構成比、同一セグメント内の変化を必要な範囲で確認してください。

3. 目標未達

月×地域で実績を Monthly Targets と比較し、revenue target達成率、gross margin targetとの差、return rate targetとの差、satisfaction targetとの差を算出してください。複数指標を同時に外した重要な未達を上位5件だけ示してください。

4. キャンペーン効率

キャンペーンごとに、予算、紐付き注文数、net revenue、gross profit、attributed ROAS、gross profit ROAS、返品率を比較してください。上位2件と改善優先2件を示してください。

キャンペーン紐付けは観測上のアトリビューションであり、増分効果ではないことを明記してください。

5. 返品・配送・満足度

商品、地域、配送日数を中心に返品率と満足度を分析し、返品が集中している条件を上位5件示してください。商品固有の問題と物流問題の切り分け候補を簡潔に説明してください。

件数が少ないグループは断定せず、必ずサンプル数を表示してください。複雑な予測モデルや網羅的なコホート分析は行わないでください。

【結論の作り方】

結論を次の3種類に分けてください。

1. データから直接確認できた事実
2. 事実から考えられる仮説
3. 次に検証すべき施策または追加データ

重要な主張には対象期間、比較対象、実数値、率、サンプル数を付けてください。相関を因果関係として説明しないでください。

【最終成果物】

分析結果を1つのPDFファイル「analysis_report.pdf」にまとめてください。PDFは5～8ページ、グラフは最大4点に制限してください。

PDFには次の内容を含めてください。

1. 表紙とエグゼクティブサマリー
   - 重要な発見3件
   - 推奨アクション3件
   - 分析上の限界
2. データ構造と品質検査の要約
3. 2024年と2025年のKPI比較
4. 重要な経営課題3件
5. 目標未達上位5件
6. キャンペーン効率
7. 返品・配送・満足度
8. 事実、仮説、次に検証すべき施策

表やグラフを詰め込みすぎず、経営層が5分で読める構成にしてください。文字切れを確認し、金額単位、率、比較対象、サンプル数、凡例を明示してください。

分析完了後、最も重要な発見、作成したPDFファイル、分析上の制約を日本語で簡潔に報告してください。
```
